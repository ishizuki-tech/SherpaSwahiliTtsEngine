# Model redistribution authorization gate

PUBLIC_REDISTRIBUTION_AUTHORIZED=false
PUBLIC_REDISTRIBUTION_AUTHORIZATION_REFERENCE=UNRESOLVED

The `vits-piper-sw_CD-lanfrica-medium` model card does not contain an explicit
license granting public redistribution of the trained ONNX model in an APK. Do
not change the authorization value to `true` until the model owner or authorized
rights holder supplies a written grant that explicitly covers public APK/model
redistribution and required attribution or other conditions.

When authorization is established, replace `UNRESOLVED` with a durable reference
to that grant, record its scope and required notices below, and have the change
reviewed before running a public Pre-release workflow.
